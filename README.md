# Amazon Homepage Clone

## About the Project
I have developed a clone of the Amazon.com homepage using HTML and CSS. This project recreates the basic layout and visual design of Amazon's website to practice and improve my front-end web development skills.

## Technologies Used
- HTML5
- CSS3

## Features
- Amazon-inspired navigation bar and header
- Search bar layout
- Product category sections
- Product cards and promotional banners
- Footer section inspired by Amazon.com

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Yaseen-Khan-Mohammad/Amazon-Home-Page.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

## Learning Outcomes
- Practiced HTML page structuring.
- Improved CSS styling and layout skills.
- Learned to recreate an existing website's visual design.
